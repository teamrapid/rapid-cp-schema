# rapid-cp-schema

LinkML schema for RAPID TA1 computable phenotypes (CPs): versioned, data-model-independent CP logic files.

- Auto-generated [schema documentation](elements/index.md)
- The [CP YAML specification](cp-yaml-spec.md): how each field is meant to be read, and how it turns into OMOP SQL (v0.1.0, by Mendelian)

The schema was drafted by Mendelian as `rapid-cp-logic` v0.1.0 and is being moved here, to a programme-neutral home for RAPID TA1.
