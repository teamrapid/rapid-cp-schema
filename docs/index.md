# rapid-cp-schema

LinkML schema for RAPID TA1 computable phenotypes (CPs): versioned, data-model-independent CP logic files.

- Auto-generated [schema documentation](elements/index.md)
- [Applying RAPID CP files in OMOP 5.4](applying-cps-omop54.md): what each field means, and how a site turns a CP into counts
- The [results-file specification](results-file-spec.md) (v1.0): the counts file each site returns to Mendelian
- The original [CP YAML specification](cp-yaml-spec.md) (v0.1.0, by Mendelian), kept for reference. It also describes Mendelian's in-house `cpsql` tool and the build and site files, which schema 0.2.0 no longer includes.

The schema was drafted by Mendelian as `rapid-cp-logic` v0.1.0 and is being moved here, to a programme-neutral home for RAPID TA1.
