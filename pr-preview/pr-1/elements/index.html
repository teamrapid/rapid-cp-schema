    rapid_cp_schema

    Schema for the two files that make up a deployable RAPID computable phenotype (CP):

    1. The CP logic file __v..yaml Data-model-independent. Says WHAT counts as evidence (features, coded in source vocabularies: ICD10CM, SNOMED, LOINC, RxNorm, ...) and HOW the evidence combines (Level 1 disjuncts, Level 2a rules, Level 2b score). Every disjunct / rule / score item carries a stable id (d1, r2, s3) that is reported back as the flag reason.

    2. The build file _.b.sql The generated SQL for one data model (e.g. OMOP 5.4), shared by every site on it, with a YAML comment header that conforms to CPBuild.

    3. Site files sites/_v.yaml Everything about one site (schemas, vocabulary release, history concepts), applied at run time.

    This schema is deliberately separate from the curation-record schema. The curation record holds the full evidence base and review trail; the CP logic file is the executable subset selected from it. Diseases are identified by Mondo ids only.

    URI: https://mendelian.co/schemas/rapid-cp-logic
